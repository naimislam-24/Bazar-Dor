## 📌 Overview

**Bazar Dor** is a modern, responsive web application built with **Next.js** to help users explore and access market price information through a clean, user-friendly interface. The application features a responsive design that works seamlessly across mobile phones, tablets, laptops, and desktop devices.

It includes secure user authentication with **Better Auth**, database integration with **MongoDB**, and a modern UI built using **Tailwind CSS, DaisyUI, and HeroUI**. The application also uses interactive notifications and scrolling announcements to enhance the overall user experience.

### ✨ Key Features

- 📱 **Fully Responsive Design** — Optimized for mobile, tablet, laptop, and desktop screens.
- 🔐 **Authentication System** — User registration, sign-in, session management, and sign-out using Better Auth.
- 🗄️ **Database Integration** — MongoDB for data storage and database operations.
- 🛍️ **Market Price Categories** — Browse market information through category-based navigation.
- 🎨 **Modern User Interface** — Clean and intuitive UI using Tailwind CSS, DaisyUI, and HeroUI.
- 🔔 **Interactive Notifications** — User feedback and alerts with React Toastify.
- 📢 **Scrolling Announcements** — Dynamic marquee content for an engaging interface.
- ⚡ **Next.js App Router** — Modern routing and component-based application architecture.
- 🧩 **Reusable Components** — Maintainable and organized code structure.
- 🚀 **Optimized User Experience** — Smooth navigation and responsive interactions across devices.

### 🛠️ Technologies Used

- **Framework:** Next.js
- **Library:** React
- **Language:** TypeScript
- **Authentication:** Better Auth
- **Database:** MongoDB
- **UI Libraries:** HeroUI, DaisyUI
- **Styling:** Tailwind CSS
- **Notifications:** React Toastify
- **Scrolling Content:** React Marquee
- **Routing:** Next.js App Router
- **Image Optimization:** Next.js Image
- **Data Fetching:** Fetch API

### 🎯 Project Goal

The goal of Bazar Dor is to provide users with an accessible and user-friendly platform for exploring market price information, with a focus on responsive design, secure authentication, and a smooth browsing experience across devices.
